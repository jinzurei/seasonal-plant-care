1. What is the title of your program?

Seasonal Plant Care Assistant

2. What real-world problem will your program address or help to solve?

Many new or busy plant owners struggle to adapt their care routines to seasonal changes, leading to common issues like root rot, yellowing leaves, or poor growth. This program provides personalized, seasonally-adjusted care tips for houseplants, helping users make small but important changes to their routine without needing to do manual research for each plant.

3. What will you learn from developing this program?

I will improve my understanding of how to:
- Work with CSV files and structured data
- Design reusable and testable functions
- Parse user input and search/filter information
- Format and display useful output in the terminal
- Use `pytest` to write and run test functions for core logic
- Apply real-world data to build a helpful and practical tool

4. What Python modules will your program use?

csv, datetime, pytest
